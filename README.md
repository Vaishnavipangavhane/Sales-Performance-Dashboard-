 📊 Sales Performance Dashboard – Excel

 📌 Project Overview
This project focuses on analyzing sales performance using an interactive dashboard built in Microsoft Excel.
It provides business insights into revenue, profit, deals, profit margins, regional performance, and product sales.

 🛠️ Tools & Technologies
- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- KPI Cards
- Data Visualization

 📈 Dashboard KPIs
- Total Revenue
- Total Profit
- Total Deals
- Profit Margin

 📊 Key Dashboard Features
- Regional Revenue Analysis
- Monthly Revenue and Margin Analysis
- Product Mix Analysis
- Top Sales Representatives
- Interactive filters for Region, Product, Salesperson, and Date

 🎯 Project Objectives
- Monitor overall sales performance.
- Compare revenue across different regions.
- Identify top-performing sales representatives.
- Understand product-wise sales contribution.
- Track monthly revenue and profit margin trends.
